# Multised talks

Slides from talks about the Multised database, published with GitHub Pages at
<https://seafood-hazards.github.io/multised-talks/>.

| Folder | Talk |
| --- | --- |
| `2026-11-19-workshop/` | Multised database, preliminary results and challenges. Baseline workshop, day 2, Bergen, 19 November 2026. |

Each talk is a single self-contained HTML deck with its narration in `assets/audio/`.
The narration is an AI-generated voice (Google Gemini TTS).

The decks are built in the `multised_summary_presentation` project and copied here with
its `src/publish.sh`. Edit them there, not here.
