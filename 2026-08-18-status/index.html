01 — the pipeline

Five generations

Each generation deposits on the one below it. Nothing skips a layer.

  • Pilot

    Each source's raw files parsed into a per-source database.

  • Slim

    Every source reshaped into the same seven-table schema, then annotated with quality-control flags.

  • Clean

    The flags are applied, units harmonised, and grain size split into its own table.

  • Merged

    The five clean databases are combined into a single database, with cross-source duplicates removed.

  • Refined

    A restructured, analysis-ready base for the pristine and background-sediment analyses.
